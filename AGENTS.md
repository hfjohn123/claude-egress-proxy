# Repository instructions

- Create branches with the `Qi/` prefix.
- Open pull requests as drafts first.
- Do not add an AI co-author trailer to commits.
- Run `go fmt ./...`, `go mod download`, `go mod verify`, `go test ./...`,
  `go vet ./...`, `go list -m all`, and `git status --short` before committing.
- Keep credentials, API accounts, personal paths, hostnames, IP addresses,
  usernames, runtime state, keys, logs, and local outputs out of the repository.
- Use reserved domains and documentation address ranges in public examples.
- Keep runtime state outside the checkout.
